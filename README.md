# discord-voice-idle

Минимальный клиент для собственного Discord-аккаунта: подключается к одному обычному голосовому каналу с выключенными микрофоном и звуком. Команд, отправки сообщений, воспроизведения и записи аудио нет. Библиотека получает события Discord и обслуживает голосовой протокол.

**Автоматизация обычных аккаунтов нарушает правила Discord. Возможны ограничения или блокировка. Это не официальный Discord-бот; гарантии непрерывной работы нет.** Используй только свой аккаунт и канал, к которому у него уже есть доступ. Проект не обходит права сервера.

## Запуск на Railway

1. В Railway создай проект: **Deploy from GitHub repo** → этот репозиторий. Если его нет в списке, разреши Railway доступ к приватному репозиторию.
2. В **Variables** добавь `DISCORD_TOKEN` — токен собственного аккаунта, без кавычек и без префикса `Bot`.
3. Добавь `VOICE_CHANNEL_ID` — числовой ID обычного голосового канала. В Discord включи **Настройки → Расширенные → Режим разработчика**, затем правой кнопкой по каналу → **Копировать ID канала**.
4. Запусти или повтори деплой. Используется Dockerfile; команду запуска менять не нужно.
5. Если включён **Serverless / сон сервиса**, отключи его. Домен, открытый HTTP-порт и HTTP healthcheck не нужны: это фоновый процесс, а не сайт.
6. В логах дождись: **Войс подключён. Микрофон и звук выключены.**

Railway должен поддерживать постоянно работающий сервис; расход и доступность зависят от тарифа. При сбое с ненулевым кодом завершения задано до трёх автоматических перезапусков. Для остановки останови сервис Railway.

## Что происходит при разрыве связи

Библиотека пытается восстанавливать сетевые соединения. Ошибка первоначального входа или подключения закрывает процесс с кодом 1. Отдельного бесконечного цикла возвращения в канал нет: программа не предназначена для противодействия отключениям и перемещениям модераторами. Возвращение в исходный канал после любого возможного сбоя не гарантируется.

## Секреты

- Не добавляй токен в GitHub, README, исходники, скриншоты или чат.
- Храни его только в Variables Railway и ограничь доступ к проекту.
- `.gitignore` и `.dockerignore` исключают локальные `.env`, но не защищают от намеренной публикации секретов.
- Сторонняя библиотека получает токен в памяти. Приватный репозиторий не устраняет риски зависимости или блокировки аккаунта.

## Проверки и ограничения

Используется `discord.py-self[voice]==2.1.0`. Проверены синтаксис, импорт голосовых зависимостей, сигнатура `VoiceChannel.connect`, параметры mute/deaf с тестовым объектом и обработка отсутствующих настроек. Вход с реальным токеном, реальный войс, сборка Docker и деплой Railway при подготовке проекта не проверялись.

Документация библиотеки: https://github.com/dolfies/discord.py-self

## Если не подключается

- `LoginFailure`: проверь авторизацию; не публикуй токен.
- `Forbidden`: проверь доступ аккаунта к серверу и голосовому каналу.
- `NotFound`: проверь ID канала и доступ к нему.
- `ValueError`: нужен обычный серверный голосовой канал, не текстовый, Stage или личный звонок.
- `TimeoutError` / `ConnectionClosed`: возможны сеть, несовместимость протокола или сбой Discord. Сначала проверь логи; повторные попытки не гарантируют исправления.

Для диагностики делись только названием ошибки и обезличенными логами, без секретов.
